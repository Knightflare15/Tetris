# Quattro assets

Runtime cat sprites are served from `/assets/quattro/sprites`.

Expected sprite layout:

- `sprites/1Block/I_block_cyan.png`
- `sprites/2Block/I_horizontal_block_cyan.png`
- `sprites/2Block/I_vertical_block_cyan.png`
- `sprites/3Block/L_block_cyan.png`
- `sprites/4Block/Z_block_cyan.png`

Add each required shape in every tetromino color: `cyan`, `yellow`, `purple`, `green`, `red`, `blue`, and `orange`.
