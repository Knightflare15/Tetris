# `package-lock.json`

## What It Does

This lockfile records the exact npm dependency tree used by Brix.

## Why It Exists

The project depends on a mix of runtime packages, build tooling, Prisma, Webpack, React, Socket.IO, and TypeScript tooling. The lockfile keeps installs repeatable across local machines, CI, Docker builds, and Azure deployment.

## Maintenance Notes

Do not edit this file by hand. Let npm update it when dependencies change through commands such as:

```bash
npm install
npm update
```

Commit this file with any dependency changes so CI and production builds use the same resolved package versions.
